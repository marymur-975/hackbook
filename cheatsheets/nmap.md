# Nmap — шпаргалка

## Базовое сканирование

```bash
# Быстрое сканирование популярных портов
nmap -F 192.168.1.1

# Полное сканирование всех 65535 портов с определением версий
nmap -p- -sV 192.168.1.1

# Агрессивное сканирование (версии, ОС, скрипты, traceroute)
nmap -A 192.168.1.1
```

````

## Продвинутые техники

```bash
# Сканирование без пинга (если хост блокирует ICMP)
nmap -Pn 192.168.1.1

# Использование NSE скриптов (поиск уязвимостей)
nmap --script vuln 192.168.1.1

# Сканирование UDP портов (медленно, но важно)
nmap -sU 192.168.1.1

# Сканирование с определенной скоростью (T0-T5)
nmap -T4 192.168.1.1
```

## Вывод результатов

```bash
# Сохранить в XML (для импорта в Metasploit)
nmap -oX scan.xml 192.168.1.1

# Сохранить в обычном и grep-формате
nmap -oN scan.txt -oG scan.gnmap 192.168.1.1

# Сохранить во всех форматах сразу
nmap -oA scan_results 192.168.1.1
```
````
