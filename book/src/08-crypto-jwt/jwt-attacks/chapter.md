# Атаки на JWT (JSON Web Tokens)

## Введение

JWT (JSON Web Token) — это стандарт передачи данных в виде токена, который часто используется для аутентификации. Если разработчики неправильно настраивают проверку подписи, злоумышленник может подделать токен и получить доступ к чужим аккаунтам.

## Алгоритм "none"

Самая простая атака: если сервер доверяет полю `alg` в заголовке токена, можно установить его в `none` и удалить подпись. Сервер примет токен без проверки.

## Подбор слабого секрета

Если токен подписан алгоритмом HS256, можно попытаться подобрать секретный ключ по словарю (например, через `hashcat`). Если ключ слабый, злоумышленник сможет подписывать любые токены.
