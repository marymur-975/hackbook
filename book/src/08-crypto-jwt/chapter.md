# Криптография и JWT

JSON Web Tokens (JWT) — это стандарт токенов, который часто используется для аутентификации. Если разработчик неправильно настроил проверку подписи, токен можно подделать.

Подробнее — в подглаве [Атаки на JWT](jwt-attacks/index.md).
